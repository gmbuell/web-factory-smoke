# Red Hill design system

- The tokens (colors and fonts) live in `site/css/styles.css`, under `:root`.
- The guidelines are the navy-and-gold Red Hill brand guide, in `guidelines/brand-guide.html`.
- This is the default starting point. Reworking it is in scope: when the board wants a different look, change the guide, the tokens and the fonts together.
- Apply it to what the board asks for; it never adds motifs, buttons or text by itself, and its sample text is not copy.
- The guide covers the look only. The one wording rule, that people's words go on the page verbatim, is in `CLAUDE.md`.
